**An `artisan`-style command line for Android projects.** Type a word and the phone switches to dark mode, takes a
screenshot, installs the build, shows missing translations, or opens Crashlytics. Written in Kotlin and runs
anywhere a JDK runs (Windows, macOS, Linux).

![artisan app: a numbered picker of every phone command](/img/app.svg)

## Why

::card-group
  :::card{icon="i-lucide-zap" title="Zero setup" to="/getting-started/configuration"}
  Run it anywhere inside a Gradle project. It finds the root, the modules (Kotlin or Groovy DSL), the app module, `applicationId`, version, and Firebase project by itself.
  :::

  :::card{icon="i-lucide-wrench" title="Easy tool setup" to="/getting-started/setup"}
  Missing Java or adb? The Windows installer and `artisan setup` reuse Android Studio's JDK and SDK, or install them with `winget` / `brew`.
  :::

  :::card{icon="i-lucide-keyboard" title="Suggestions as you type" to="/commands/overview"}
  At your normal prompt, `artisan da` shows `app:dark` in gray as you type; → accepts. Or run `artisan` and type to search every command (`dark`, `translation`, even `drak`).
  :::

  :::card{icon="i-lucide-factory" title="Generators for the repetitive parts" to="/commands/make"}
  `make:string` (every locale at once), `make:event` + `check:events`, `make:screen`, `bump`, `make:bundle`, `make:analytics`.
  :::

  :::card{icon="i-lucide-terminal" title="In your terminal, not only a CLI" to="/commands/terminal"}
  Ctrl+g hotkeys, project status in your prompt, git hooks that stop commits with event.md or translations out of sync, clickable output paths.
  :::

  :::card{icon="i-lucide-list-checks" title="Pickers instead of memorising" to="/commands/overview"}
  `artisan make`, `artisan app` and `artisan open` show just that group's commands. Leave out a value (`artisan app:font`) and it shows the choices.
  :::

  :::card{icon="i-lucide-smartphone" title="Phone switches for QA" to="/commands/phone"}
  Dark/light, font scale, rotation, per-app language, screenshot, screen recording, logcat, type text, deep links, permissions, clear data, demo status bar, mirror.
  :::

  :::card{icon="i-lucide-heart-pulse" title="Project health" to="/commands/code-health"}
  Missing translations per module × language, TODO/FIXME summary, lines of code, `doctor`.
  :::

  :::card{icon="i-lucide-notebook-pen" title="Optional notes workspace" to="/commands/notes"}
  Versions → phases → bugs, plans, and screenshots for a team or an AI agent: `make:plan`, `make:bug`, `status`, `list:verify`.
  :::

  :::card{icon="i-lucide-puzzle" title="Your own commands" to="/commands/custom-commands"}
  Add shell commands in `artisan.json` and they show up in the pickers.
  :::
::
