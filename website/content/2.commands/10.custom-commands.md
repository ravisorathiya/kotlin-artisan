---
title: Your own commands
description: Add your team's shell commands to artisan.json. They show up in pickers and search and Tab completion.
navigation:
  icon: i-lucide-puzzle
---

In `artisan.json`:

```json [artisan.json]
"commands": {
  "deploy:beta": { "description": "Upload a beta build", "run": "./gradlew appDistributionUploadRelease" },
  "lint":        { "description": "Android lint, debug variant", "run": "./gradlew lintDebug" }
}
```

They run from the project root through `sh -c` (Windows: `cmd /c`), appear in `artisan list`, and a `group:name`
joins (or creates) that group's picker (`artisan deploy`). Tab completion picks them up from the nearest
`artisan.json`, and you can bind one to a [hotkey](/commands/terminal#hotkeys): `"hotkeys": {"u": "deploy:beta"}`.
