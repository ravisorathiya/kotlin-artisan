Run any command from any folder inside a Gradle project. `artisan` and `kotlin-artisan` are the same program.

## Search as you type

Run `artisan` with nothing after it (or `artisan find <words>`) and start typing. The list filters with every key:
by name (`dar`), by word (`dark` → `app:dark`), by initials (`cs` → `check:strings`), by description
(`translation` → `check:strings`), and through typos.

| Key | Does |
|---|---|
| :kbd{value="↑"} / :kbd{value="↓"} (Ctrl+P / Ctrl+N), PgUp / PgDn | Move the highlight |
| :kbd{value="Tab"} | Fill in the highlighted command; press again for its values (`app:rotate ` → `land` / `port` / `auto`) |
| :kbd{value="Enter"} | Run it. A value that isn't in the list (`app:font 1.7`) runs as typed. The direct command is printed first |
| Backspace, Ctrl+W, Ctrl+U | Delete a character, a word, everything |
| Esc, Ctrl+C | Quit |

When the output isn't a terminal (pipe, CI, AI agent), `artisan` prints the list and `artisan find <words>` prints
the matching commands as a table.

## Tab completion

`artisan completion --install` turns it on for the shell you run it from (PowerShell, bash, zsh, fish; or name one:
`artisan completion zsh --install`). It writes the script into artisan's state folder and adds one line, tagged
`# kotlin-artisan completion`, to your profile (`$PROFILE`, `~/.bashrc`, `~/.zshrc`; fish reads
`~/.config/fish/completions/artisan.fish` by itself).

`artisan app:<Tab>` then completes commands with their descriptions, the values after a command, flags, and the
commands in the nearest `artisan.json`. Typing part of a name works too: `artisan dark<Tab>` → `app:dark`.

- In PowerShell, Tab opens a menu with the description of the highlighted item (only when Tab still has the default
  binding; `ARTISAN_NO_MENU_TAB=1` leaves it alone). Windows PowerShell 5.1 completes the `--plain` / `--table` flags
  but not single-dash ones.
- The script is plain shell code, so Tab never starts Java, and artisan rewrites it after an update.
- `artisan completion <shell>` prints the script without installing anything. To turn it off, delete the tagged line.

::note
cmd.exe has no Tab completion API: use plain `artisan` there.
::

## Suggestions while you type

The same install also suggests as you type at the normal prompt, without Tab. Type `artisan da` and the best match
appears as gray text after the cursor (`rk [on|off]`); press :kbd{value="→"} to accept it. A command that takes a
value gets a space after it, so `artisan app:rotate ` then suggests `land` / `port` / `auto`. A match that doesn't
start with what you typed shows where it leads (`artisan dark` → `-> app:dark`).

| Shell | What you get |
|---|---|
| Windows PowerShell 5.1 | artisan draws the gray text, plus up to five matches with descriptions under the line (when there's room below it in the window). It only uses keys that still have PSReadLine's default binding |
| PowerShell 7.2+ | artisan's predictor module plugs into PSReadLine's own predictions (gray text, F2 for the list view). It turns `PredictionSource` on for plugins if it was off |
| zsh | With zsh-autosuggestions installed, completions become a suggestion source |
| fish | Built in: fish suggests from the completions |
| bash, cmd.exe | No way to hook in: use plain `artisan` |

`ARTISAN_NO_LIVE_HINTS=1` (set before your profile runs) turns them off.

## Pickers

Type only a group (`artisan make`, `artisan app`, `artisan open`, `artisan check`) to pick one of its commands. A
group with one command (`del`, `build`) runs it directly. Leave out a value and the command asks, as a picker when
the choices are fixed. In a picker, type the number or the option's name; **Enter cancels**.

A typo (`artisan app:drak`) asks whether you meant `app:dark`; a vaguer one lists the closest matches.

## Flags

| Flag | Effect |
|---|---|
| `-y` | Skips "yes" confirmations |
| `-v` | Shows details |
| `-md` | Prints markdown (`list:verify`) |
| `--plain` / `--table` | Force the output style (below) |

## Plain output for scripts and AI agents

When stdout isn't a terminal (pipe, file, AI agent), every table prints as `== Title ==` followed by tab-separated
lines (header first) with no borders and no truncation: about half the size, and ready for `cut -f2` /
`awk -F'\t'`. `--plain` forces it in a terminal, `--table` forces boxes in a pipe; `ARTISAN_PLAIN=1|0` sets the
default. Set `ARTISAN_DEBUG=1` to get the stack trace when something fails unexpectedly.

## Colours

Green = OK/done, yellow = needs attention / `VERIFY ON DEVICE`, red = failed/blocked. Long text is cut with `...` to
fit the terminal.
