Issues and PRs welcome. Bug reports with the output of `artisan doctor` and `ARTISAN_DEBUG=1 artisan <command>` are
the most useful.

## Build and test

```sh
./gradlew test installDist
build/install/kotlin-artisan/bin/artisan list      # Windows: build\install\kotlin-artisan\bin\artisan.bat list
```

Run it inside any Android project to try a change.

## Adding a command

```kotlin
Registry.add("app:wifi", "app:wifi [on|off]", "Turn Wi-Fi on or off") { ctx ->
    requireAdb()
    val on = ctx.arg(0) ?: listOf("on", "off")[Ui.pick("Wi-Fi", listOf("on" to "Enable", "off" to "Disable"))]
    adbShell("svc", "wifi", if (on == "on") "enable" else "disable")
    Ui.say("Wi-Fi: $on", Tone.OK)
}
```

- A missing value means a question (`Ui.ask`) or a picker (`Ui.pick`). Never a usage error.
- Results go in `Ui.table`, expected failures in `throw CliError("...")`, backing out in `throw Cancelled`.
- Anything destructive goes through `Ui.confirm` (it respects `-y`).
- Keep it working on Windows, macOS and Linux (`Os`, `Proc`, `File` paths, no shell-specific syntax).
- Add a test for parsing/detection logic, and document the command (below) and in `CHANGELOG.md`.

## Documenting it on this site

The site lives in [`website/`](https://github.com/ravisorathiya/kotlin-artisan/tree/main/website) and is built with
[Docus](https://docus.dev) (Nuxt + Nuxt UI + Tailwind CSS). A new command gets its row in
`website/content/2.commands/<group>.md`, in the same PR as the code. Every page has an *Edit this page* link.

```sh
cd website
npm install
npm run dev          # http://localhost:3000
```

Pull requests that touch `website/` get a Netlify deploy preview.

The full guide, including releasing, is in
[CONTRIBUTING.md](https://github.com/ravisorathiya/kotlin-artisan/blob/main/CONTRIBUTING.md).
