# Skills

How this repo does a task that comes up again and again. A task (in `workflow/`) says *what*; a skill says *how*.

| Skill | Use it when |
|---|---|
| [add_command.md](add_command.md) | A new command or flag, or a change to what one does |
| [docs_site.md](docs_site.md) | A page in `docs/` (the GitHub Pages site) |
| [ai_templates.md](ai_templates.md) | What `make:ai` writes into Android projects (`src/main/resources/templates/ai/`) |
| [release.md](release.md) | Shipping a version |

Add a skill when a kind of task comes up the second time. Keep it current with the code it describes.
